# روبوت تحديد الموقع والترجمة التلقائية

## الفكرة

عند أول دخول للموقع يكتشف **روبوت الموقع الجغرافي** دولة الزائر ولغته من مصدر الدخول (IP + لغة المتصفح + المنطقة الزمنية) ويفتح الموقع تلقائياً بتلك اللغة — دون أن يفقد الزائر حق التغيير اليدوي.

> **القاعدة:** التشغيل تلقائي حسب اللوكيشن، والتغيير اختياري دائماً.

## كيف يعمل؟

```
?lang=xx  →  أعلى أولوية (رابط مشارك)
    ↓
استهداف سابق للروبوت (insco_robot_lang_v1)  →  احترم اختيار المستخدم
    ↓
علامة يدوية (30 يوم) أو تجاهل البانر (7 أيام)  →  لا تزعج المستخدم
    ↓
IP → دولة → لغة (insco_geo_detected_v1، كاش 24 ساعة)
    ↓
لغة المتصفح (navigator.language)
    ↓
المنطقة الزمنية (Intl.DateTimeFormat → Europe/Paris → FR → fr)
```

- **IP** هو المصدر الأساسي للوكيشن. يُجرّب 4 نقاط نهاية مجانية متسامحة مع CORS:
  `ipapi.co/json`، `countries.dev/ip`، `ipwho.is/`، `get.geojs.io/v1/ip/geo.json` — مهلة 2.5 ثانية لكل واحدة.
- **المتصفح** احتياطي فوري عند فشل الشبكة أو الـ VPN.
- النتيجة تُحفظ 24 ساعة لتجنب ضرب الـ API مع كل تحديث.

## ماذا يحدث بعد الاكتشاف؟

| اللغة المكتشفة | الإجراء التلقائي |
| --- | --- |
| `ar` أو `en` (لغتا الموقع الأصليتان) | يقلب مفتاح اللغة الأصلي في `App` — ترجمة مثالية، بدون آلة |
| أي لغة عالمية أخرى (fr، de، ja، ur …) | يشغّل **روبوت الترجمة** (`translationRobot.enable(code, {manual:false})`) — ترجمة آلية للـ DOM مع كاش محلي ومراقب حيّ |

في الحالتين يظهر بانر علوي صغير يوضّح:

> 🇫🇷 موقعك: فرنسا — باريس • تم فتح الموقع تلقائياً بالفرنسية — تغيير اللغة اختياري دائماً. [العودة للعربية] [تغيير اللغة]

- يختفي تلقائياً بعد 14 ثانية.
- زر **العودة** يلغي الترجمة ويضع علامة يدوية (30 يوم).
- زر **تغيير اللغة** يفتح لوحة الروبوت.
- إغلاق البانر يضع علامة تجاهل (7 أيام).

## لوحة الروبوت — عرض اللوكيشن

لوحة الترجمة العائمة الآن تُظهر قسم اللوكيشن في الأعلى عند توفره:

```
📍 موقعك: 🇫🇷 فرنسا — باريس (FR) • عبر الموقع
[✨ ترجمة إلى Français (French)]
الترجمة تلقائية حسب موقع دخولك — تغيير اللغة اختياري دائماً.
```

- إذا لم يكتمل كشف الـ IP بعد، يظهر اقتراح لغة المتصفح القديم كاحتياطي.
- الشارة على زر الروبوت تُظهر كود اللغة النشطة (مثلاً `FR`).

## التخزين المحلي

| المفتاح | المحتوى | المدة |
| --- | --- | --- |
| `insco_robot_lang_v1` | اللغة النشطة للروبوت | دائمة حتى الاستعادة |
| `insco_robot_manual_v1` | طابع زمني لآخر تغيير يدوي | 30 يوم |
| `insco_geo_dismissed_v1` | تجاهل البانر | 7 أيام |
| `insco_geo_detected_v1` | آخر دولة/لغة مكتشفة + كاش IP | 24 ساعة |
| `insco_geo_auto_v1` | آخر ترجمة تلقائية (للبانر) | حتى التغيير |
| `insco_translation_cache_v1` | كاش الترجمات الآلية | 600 إدخال |

مسح أي منها من DevTools يعيد السلوك الافتراضي.

## الخصوصية

- لا API keys ولا كوكيز تتبع.
- طلب الـ IP يرسل عنوان الـ IP فقط لنقطة النهاية الجغرافية العامة — لا يُرسل محتوى الصفحة.
- الترجمة ترسل النص الظاهر فقط لـ MyMemory/Google Translate.
- كل شيء يعمل بدون اتصال بعد أول ترجمة بفضل الكاش.

## الاختبار

```bash
npm run test:geo          # خريطة الدول + كشف الـ IP + القرار التلقائي
npm run test:translator   # واجهة الروبوت وترجمة الـ DOM
npm run build && npm run site:check  # بناء docs/ وتحقق النشر
```

## حدود معروفة

- الـ VPN/البروكسي قد يكشف دولة غير صحيحة — عندها لغة المتصفح هي الأدق، والروبوت يسمح بالتغيير بنقرة.
- بعض المناطق الصغيرة (مثلاً FO جزر فارو) تُسند إلى لغة الجار (da).
- الترجمة آلية: المصطلحات الفنية الدقيقة (NDT/PWHT/ASME) قد تختلف صياغتها — المرجع الرسمي هو العربية/الإنجليزية الأصلية.
