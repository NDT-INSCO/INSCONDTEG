# AR/EN Glossary (Pilot — UT focus)

| Term (EN) | Term (AR) | Notes |
|---|---|---|
| Ultrasonic Testing (UT) | الاختبار بالموجات فوق الصوتية | Method name |
| Pulse-echo | نبضة-صدى | Common UT mode |
| Time of flight (TOF) | زمن الرحلة | Round-trip unless stated otherwise |
| Probe / Transducer | مسبار / محول | Use consistently; prefer "مسبار" in UI, define once |
| Wedge delay | تأخير الوتد | Calibration compensation |
| Probe delay | تأخير المسبار | Zero offset / electronic delay |
| Couplant | وسيط اقتران | — |
| Near field / Fresnel zone | المنطقة القريبة / منطقة فرينل | — |
| Far field / Fraunhofer zone | المنطقة البعيدة / منطقة فراونهوفر | — |
| Beam spread | انتشار الحزمة | — |
| A-Scan / B-Scan / C-Scan | عرض A / عرض B / عرض C | Keep scan letters |
| Gate | بوابة | Time/amplitude window |
| DAC (Distance Amplitude Correction) | منحنى تصحيح المسافة والسعة (DAC) | Reference comparison curve |
| TCG (Time Corrected Gain) | تعويض الكسب مع الزمن (TCG) | Not identical to DAC |
| DGS/AVG | طريقة DGS/AVG | Use only with proper reference context |
| Dead zone | المنطقة الميتة | Near-surface limitation |
| Resolution | الدقة / القدرة على الفصل | Distinguish from accuracy |
| Sensitivity | الحساسية | — |
| Calibration block | كتلة معايرة | Specify type by procedure |
| Reference reflector | عاكس مرجعي | SDH/FBH/notch as applicable |
| Skip distance | مسافة القفزة | — |
| Index point | نقطة الخروج | Verify before scan |
| Angle beam | حزمة مائلة | — |
| Discontinuity | انقطاع | Neutral term |
| Flaw | عيب | Use carefully; may imply rejectable per code context |
| Indication | إشارة / دلالة | Response observed; needs evaluation |
| Acceptance criteria | معايير القبول | Code/procedure specific; edition required |
