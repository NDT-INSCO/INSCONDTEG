# إنسكو — نشر الإصدار الثاني والتحقق من الخدمات الحية

## نطاق النشر العام

ينشر GitHub Pages مجلد `main:/docs` على [الموقع الرسمي](https://ndt-insco.github.io/INSCONDTEG/). يُبنى على المسار `/INSCONDTEG/` وتُطابَق ملفاته مع المصدر قبل الدمج. [مقارنة الواجهة واختباراتها المعملية](QA_V2_AR.md) تخصّ معاينة الإصدار قبل دمج تحديثات الشبكة، وليست إثباتًا لخدمة خارجية.

- دمج النشر يحافظ على بطاقة المهندس والدليل والمنشورات والتعليقات والتفاعلات وطلبات الاتصال الموجودة في `main`. لها جلسة الحساب العام نفسها. «ملفي الخاص» يفتح `#client/register`، وليس البطاقة المهنية العلنية. لا تغيير لقواعد Firebase أو معرّف المشروع أو قاعدة البيانات.
- ينشر الموقع [المقتطف التاريخي فقط](DOSSIER_PUBLIC_V2_AR.md)، وتُطلب الملاحق من الشركة بقناة خاصة. لا يعدّ المعروض إثباتًا لسريان المعايرة أو للترخيص. لا يزيل استبدال الملف النسخة الأصلية من سجل Git أو مخابئ خارجية؛ لا تعِد رفعها، وتولَّ طلب حذف المخزون القديم إن لزم كإجراء منفصل من مالك المستودع.
- لا يُنقل الموقع إلى خادم آخر أثناء هذا النشر. `build:hosted` للبوابة ذات الخادم عند اعتمادها. إذا لم تُضبط قناة HTTPS لعرض السعر، يبقى نسخ المسودة والتواصل اليدوي متاحَين، من غير إرسال تلقائي أو رقم استلام. لا يُفعّل المستشار التعليمي مع محتوى غير مراجَع.

## قبول النشر

1. تطابق [عملية بناء Pages الأخيرة](https://github.com/NDT-INSCO/INSCONDTEG/actions?query=workflow%3Apages-build-deployment) مع commit الدمج، مع نجاح اختبارات البناء والخصوصية. افحص الرابط العام نفسه؛ نجاح البناء وحده ليس دليلًا أن زائرًا يرى النسخة الجديدة.
2. افتح الرئيسية ثم [خدمة RT](https://ndt-insco.github.io/INSCONDTEG/#services/ndt/rt)، [الأكاديمية](https://ndt-insco.github.io/INSCONDTEG/#academy)، [الشبكة](https://ndt-insco.github.io/INSCONDTEG/#network/profile)، وصفحة [طلب السعر](https://ndt-insco.github.io/INSCONDTEG/#rfq). لا ترسل بيانات عميل في اختبار النشر. تحقق أن PDF العام 50 صفحة، وبصمته `ccbfdffbc2b8c5dfdf9e8ca9146c77b118e9afea58597f2a3a07d3e4b4ab926e` بعد تحديث الخادم والمخبأ.
