# مترجم إنسكو الذكي — ترجمة الموقع لجميع لغات العالم

## ما هو؟

الموقع أصلي بالعربية والإنجليزية. **مترجم إنسكو الذكي** (Translator Robot) هو
روبوت عائم يظهر في كل صفحات الموقع (الشركة، العملاء، الأكاديمية، الشبكة) ويترجم
المحتوى المرئي كاملاً — فوراً ودون إعادة تحميل — إلى أكثر من **110 لغة** حول العالم.

## كيف يستخدمه الزائر؟

1. يضغط زر الروبوت 🤖 أسفل الشاشة (زر «ترجمة / Translate»).
2. يبحث عن لغته أو يختارها من القائمة (الأكثر استخداماً + كل لغات العالم).
3. تُترجم الصفحة فوراً مع شريط تقدّم، ويُقلب اتجاه الصفحة (RTL/LTR) تلقائياً
   للغات مثل الأردية والفارسية والعبرية.
4. عند التنقل بين الصفحات أو فتح محتوى جديد (React يعيد الرسم) يترجم الروبوت
   المحتوى الجديد تلقائياً.
5. للعودة للغة الأصلية: زر «استعادة / Restore» أو اختيار «اللغة الأصلية».

## مزايا إضافية

- **اكتشاف لغة المتصفح**: عند أول زيارة يقترح الروبوت لغة متصفح الزائر بزر واحد.
- **روابط قابلة للمشاركة**: `?lang=fr` أو `?translate=ja` تفتح الموقع مترجماً مباشرة.
- **حفظ التفضيل**: اختيار اللغة يُحفظ في المتصفح ويُستعاد عند الزيارة التالية.
- **ذاكرة ترجمة**: كل ترجمة تُحفظ محلياً، فالصفحة المترجمة سابقاً تعمل حتى بدون اتصال.

## كيف يعمل تقنياً؟

| الملف | الدور |
| --- | --- |
| `src/i18n/languages.ts` | سجل اللغات (الكود، الاسم الأصلي، الاتجاه) + اكتشاف لغة المتصفح |
| `src/i18n/translateEngine.ts` | محرك الترجمة: MyMemory أولاً ثم Google Translate، مع كاش محلي |
| `src/i18n/translationStore.ts` | الروبوت نفسه: يمشي في DOM، يترجم النصوص والـ placeholders، ويراقب التغييرات بـ MutationObserver |
| `src/components/TranslatorRobot.tsx` | واجهة الروبوت العائمة (زر + لوحة بحث) |
| `tests/translatorRobot.test.tsx` | 14 اختباراً: السجل، المحرك، التخزين، الواجهة |

- لا مفاتيح API ولا تكلفة: المزودان مجانيان وبدون تسجيل.
- لا يُترجم: واجهة الروبوت نفسها، الأكواد والروابط وأرقام الهواتف والبريد،
  ومحتوى `<script>/<style>/<code>`.
- النص الأصلي محفوظ لكل عنصر، فالاستعادة دقيقة 100%.

## حدود معروفة

- الترجمة آلية: المصطلحات التقنية (NDT/PWHT/ASME…) قد تختلف صياغتها قليلاً
  بين اللغات — المحتوى الأصلي بالعربية/الإنجليزية هو المرجع الرسمي.
- MyMemory المجاني له حد يومي للزائر المجهول؛ عند بلوغه يتحول الروبوت
  تلقائياً إلى Google Translate، وعند تعطل الاثنين يعرض رسالة مع زر إعادة.
