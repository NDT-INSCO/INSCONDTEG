## ما اجتاز الاختبار

- **الرئيسية والخدمات:** اختُبرت على `320 / 390 / 768 / 1024 / 1280 / 1440` بكسل، بالعربية والإنجليزية ومع الثيمين. تنقّل من «استكشف خدماتنا» إلى خدمة RT ثم نموذج طلب السعر المضبوط عليها، وظهر نسخ المسودة بدل الإرسال على Pages غير المهيّأ. الوصول للمعدات والخرائط وأداة QR، وتجاوز الترويسة بلوحة المفاتيح. لا تمدّد أفقي ولا أخطاء موارد/JavaScript مسجلة في هذه العينة. [نتيجة العروض الستة](evidence/v2/home.jsonl).
- **المسارات ولوحة المفاتيح:** على هاتف عربي ومكتب إنجليزي، اختُبر إغلاق القائمة ودليل البوابات والحساب والمساعد ومعرض الصور بـ Escape واستعادة التركيز؛ واحتواء Tab وShift+Tab داخل الحوارات. اختُبر البحث عن ISO وإغلاق النتائج، الإعدادات، روابط الأقسام عند الدخول المباشر والرجوع والتقدّم، وثبات الثيم واللغة. `axe-core 4.11.1` لم يجد مخالفات ضمن قواعد WCAG A/AA المختارة في ثلاث عينات رئيسية وعينة البحث المفتوح؛ لا يُغني عن قارئ الشاشة أو تدقيق كامل.
- **العروض:** الروابط الخمسة تفتح أدواتها عند الطلب، ولا يعمل أكثر من معمل في الوقت نفسه. اختُبر إغلاق العرض وإعادة فتحه من نفس الرابط، تبديل الوضع بـ Space، WebGL برمجي على الهاتف وبديل بدون WebGL على المكتب، واحترام تقليل الحركة.
- **الأكاديمية والبوابات:** دليل التخصصات، مقرر ← درس ← تحديده مكتملًا ← التقدّم، وخطة مذاكرة بلا بيانات هوية أو حجز. روابط شركات العملاء وفرص الشبكة والحساب العام قابلة للوصول. ظهرت بدائل المكتبة للمستشار غير المهيّأ. [نتيجة المسارات الموسعة](evidence/v2/journeys.jsonl).
- **البناء والتطابق:** `npm run verify`: 355 اختبارًا ناجحًا في 31 مجموعة، وفحوص الأنواع والمكتبة والروابط وبناء Pages. EDB: 18 كتابًا و157 صفحة، وEPUB: 18 كتابًا. طابق `npm run docs:check` ملفات Pages الـ127 في `523856b` مع بناء جديد. نجح بناء `dist/` وفحص قواعد Firestore محليًا. خدم اختبار Node الصفحة وملفاتها من الجذر، وردّ RFQ غير المهيّأ بـ `503` بلا رقم إقرار، والمستشار بلا مصدر مراجَع أو مفتاح. بقي تنبيه حجم بعض الحزم الاختيارية، خاصة الأكاديمية؛ القياس لا يدّعي أن كل مسار خفيف.
- **ملف التأهيل:** نفس مقتطف الـ50 صفحة في المصدر وبنائي Pages وNode؛ 3,128,482 بايت والبصمة `ccbfdffbc2b8c5dfdf9e8ca9146c77b118e9afea58597f2a3a07d3e4b4ab926e`. الصفحات 18–49 لا تحتوي صور المستندات الأصلية أو مرفقات. [حدود التوزيع](DOSSIER_PUBLIC_V2_AR.md).

## قبل الموافقة على النشر

1. **عرض السعر:** اعتماد جهة استقبال خاصة، ثم طلب اختبار غير حقيقي والتحقق من مطابقة مرجع الإقرار لسجل الاستلام. قبول مزوّد البريد لا يثبت وصول الرسالة. نسخة Pages غير المهيّأة لا تدّعي أن المسودة أُرسلت. [إعداد القناة](../RFQ_AR.md).
2. **الحساب:** فحص Email/Password ورسالة التفعيل واستعادة كلمة المرور من الأصل الذي سيُنشر عليه الموقع، بحساب اختبار والمشغّل المعتمد. اختبارات الحساب الحالية تعزل Firebase أو تستخدم بدائل محلية؛ لم تُغيّر القواعد أو المزوّد.
3. **المستشار والأدلة:** اعتماد المحتوى والمعدات والوثائق من أصحابها. سجل الدروس الحالي بلا مراجعات مكتملة، ولذلك لا يرسل المستشار أسئلة المتعلمين لمزوّد توليد عند غياب مصدر مطابق. اختبار مطابقة طبعة في بيئة معزولة ليس مراجعة بشرية ولا توليدًا حيًا. [حدود الأكاديمية](ACADEMY_TRUST_V2_AR.md).
4. **المستندات السابقة:** تأكيد موافقة المالك على نشر المقتطف والصور. استبدال الملف في البناء لا يسحب النسخة السابقة من النشر أو ذاكرة التخزين أو تاريخ Git. لا تعِد نشر النسخة الأصلية.

## إعادة الاختبار محليًا

من جذر المستودع، بعد `npm ci`:

```bash
SITE_BASE=/INSCONDTEG/ npm run verify
npm run docs:check          # مقارنة البناء مع docs/ في HEAD، بعد حفظ البناء في Git
npm run build:hosted        # بناء مختلف في dist/؛ لا يستبدل docs/
npm run lint:rules
npm ci --prefix scripts/ux-smoke
npm run --prefix scripts/ux-smoke compare
```

للمسارات التفاعلية، شغّل `npm run preview -- --host 0.0.0.0 --port 4173` في جلسة منفصلة ثم شغّل `npm run --prefix scripts/ux-smoke home` و`npm run --prefix scripts/ux-smoke journeys`. افتراضيًا يقرأ الاختبار `http://127.0.0.1:4173/INSCONDTEG/` **داخل بيئة الاختبار** ويوقف الاتصالات الخارجية، حتى لا يستخدم بيانات عميل أو قناة إرسال فعلية. يمكن ضبط `QA_URL` و`QA_OUTPUT`، أو `CHROMIUM_EXECUTABLE` لمتصفح محلي بدل نسخة Chromium لبيئات Linux. لنسخة Linux قد تحتاج مكتبات NSS للنظام. هذه اختبارات Chromium وليست قياسًا على أجهزة مادية أو Safari. ملف PDF الخاص بتمرين RT في جذر المستودع ناتج عن بعض الاختبارات؛ لا تضمّن إعادة توليده في فرق الإصدار.

### اختبار عودة البانر المتحرك للرئيسية

تخص قياسات الجدول أعلاه الإصدار الثابت السابق. البانر الحالي يعيد تخطيط المقدّمة القديمة **أسفل التنقّل المثبّت**: يتحرك الأنبوب خلف اسم الشركة وأزرارها ومؤشراتها، لا خلف أشرطة التنقّل والحساب، ولا في بطاقة منفصلة. تعرض البطاقات أرقام الملف مع توضيح حدودها؛ المشهد وقيمه محاكاة، لا إعدادات تشغيل أو دليلًا على المعايرة أو الترخيص.

يُحمّل مشهد WebGL بعد ظهور البانر. يتوقف الرسم المستمر عند الإيقاف، أو مغادرة البانر، أو إخفاء الصفحة. تظل الكاميرا وأوضاع الفحص قابلة للتغيير أثناء الإيقاف. تظهر صورة ثابتة عند غياب WebGL أو طلب تقليل الحركة؛ في الحالة الثانية يمكن اختيار 3D يدويًا دون دوران تلقائي. يظل فهرس العروض `#demo` منفصلًا ولا يفتح المشهد قبل اختياره.

شغّل `npm run --prefix scripts/ux-smoke banner` على معاينة بناء Pages. يفحص الاختبار أن الشريط يبقى منفصلًا بينما تتغيّر إطارات البانر، والسحب بالفأرة واللمس، وأوضاع PAUT/RT/PWHT والكاميرا وطيّ الأدوات، والإيقاف والرسم عند الطلب. ويفحص العرض الثابت والروابط إلى طلب السعر والمقتطف العام للشركة وبوابتي العملاء والأكاديمية وصفحة العروض، دون إرسال طلب أو تسجيل حساب.
