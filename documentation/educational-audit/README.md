## Governance rule

No educational content may be described as **technically approved** until:
1. The technical reference is identified (publisher, title, edition/revision, clause/section/page as applicable).
2. A qualified SME/Level III reviewer signs off the specific content version.
3. Assessment answers and acceptance-criteria logic are reviewed.
4. The lesson metadata records review status and date.

## Important boundary

INSCO Academy content is for training/learning support. It does **not** by itself grant certification, qualification, authorization to sign reports, or acceptance/rejection authority. Final decisions follow the applicable code edition, approved procedure, contract requirements, and qualified personnel.
